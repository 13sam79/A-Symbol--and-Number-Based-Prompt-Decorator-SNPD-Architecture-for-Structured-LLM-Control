A Symbol- and Number-Based Prompt Decorator (SNPD) Architecture for Structured LLM Control
Authors:

Seyed Amir Hossein Mousavi Nassab & Maryam Chinipardaz
This repository contains the complete experimental data, prompt sets, rules, and results related to the paper:
“A Symbol- and Number-Based Prompt Decorator (SNPD) Architecture for Structured LLM Control”

Repository Contents
1. Rules File

File: rule.docx
Contains all the Prompt Decorator rules in both Persian and English.
The Persian and English versions are exact translations of each other and contain identical content.

2. Experimental Results

File: result all.xlsx
Contains all experimental results obtained from the conducted tests.

3. Prompt Sets (Experiment Files)
The tested prompts are organized into two main themes:

Writing theme
Coding theme

Each theme is stored in a separate folder. Inside each folder, the prompt files are named and categorized based on the number of symbols used:

2-symbol prompts
3-symbol prompts
4-symbol prompts

All prompts are provided in both Persian and English. The Persian and English versions of each prompt are identical in meaning and structure (exact translations of each other).
The prompts were designed based on:

15 randomly generated prompts
Daily routine scenarios

in the two themes mentioned above (writing and coding).

Notes

All data, rules, and abbreviations of English alphabet letters are explained in both Persian and English.
There is no difference between the Persian and English versions of the rules or prompts; they are precise translations of each other.
